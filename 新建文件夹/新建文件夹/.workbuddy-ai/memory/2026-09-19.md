## 踩过的坑（重要）
1. **正文变蓝**：`force_black` 在添加新 run 之前执行，新 run 的 rPr 仍是蓝色 → 改为保存前遍历 body 所有 `w:color` 统一置黑。

5. **match 键名不匹配**：MASTER 用 `size`，但 `get_para_fmt` 输出 `sz` → 校验全误报。
6. **`make_caption_paragraph` 没加文字 run**：只改了 jc=center，图/表题是空白段。
7. **模板自身矛盾**：模板"写明的规范"（正文宋体、英文摘要 Times New Roman 小四、结论标题加粗、图题五号宋体）与其母段落实际 XML 并不一致 → 最终以"模板写明的规范"为准做强制统一。
